# GD GPT

AI-powered level builder for Geometry Dash.

Talk to the AI in the editor, switch themes, generate extreme sections, place Clubstep monsters, add triggers & groups, and get visual previews before accepting changes.

### Supported themes
- Hell / Infernal
- Cyber / Neon
- Abyss / Void
- Blood / Crimson
- Ice / Frost
- Factory / Industrial
- Cosmic / Space
- Nature / Forest

### Example commands
- `theme hell`
- `make clubstep monster`
- `generate extreme section at 6.7 seconds`
- `combine tidal wave layout with thinking space 2 deco`

More features coming soon!
