# GD GPT

**AI level builder mod for Geometry Dash** (Geode)

Create extreme demon layouts with themes, Clubstep monsters, gameplay, decoration, triggers, groups, visual preview, and natural language commands.

## Features (in progress)

- Natural language themes (`theme hell`, `theme cyber`, `abyss`, `blood`...)
- Place any objects, triggers, groups
- Difficulty control + precise timing
- Visual ghost preview
- Clubstep Monster & iconic structures
- Inspiration from real levels + combining styles
